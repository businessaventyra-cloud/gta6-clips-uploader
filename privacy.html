Privacy Policy

Last updated: November 15, 2026

GTA6 Clips Uploader ("the tool") is a private tool run by a single operator on their own computer. It is not offered to the public and has no user accounts.

YouTube API Services

The tool uses YouTube API Services to upload videos. Use of the tool is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

TikTok API

The tool also uses TikTok for Developers (Login Kit and Content Posting API) to upload videos to TikTok accounts owned by the operator. It requests the scopes user.info.basic and video.upload (and video.publish if direct posting is approved). It uploads the finished video file and its caption to the account that granted access, and reads only the basic profile information needed to identify that account.

The tool does not collect, store or share data about any other TikTok user. TikTok access and refresh tokens are kept in local files on the operator's computer and are used only to call TikTok APIs. Access can be removed at any time in TikTok under Settings and privacy, Security, Apps and services.

What the tool accesses

The tool requests one OAuth 2.0 scope: https://www.googleapis.com/auth/youtube.upload. With it, the tool can upload videos (file, title, description, category, privacy status) to the YouTube channel that granted access. It calls a single API method, videos.insert.

The tool does not read, collect or store YouTube user data: no viewer information, comments, subscriber lists, watch history, analytics or data about any other channel.

What the tool stores

  • OAuth tokens for the operator's own channels, kept in local files on the operator's computer. They are never sent anywhere except to Google to authenticate API requests.
  • Upload log: the YouTube video ID and upload time of each video the tool uploaded, kept in a local database, to avoid uploading the same video twice.

No data is stored on any server, and nothing is shared with, sold to or transferred to third parties. The tool uses no cookies, analytics or advertising trackers. This website does not collect personal data.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the stored tokens stop working. The stored tokens and the upload log are deleted by deleting the tool's local files; a deletion request sent to the contact address below is completed within 7 days.

Children

The tool is not directed to children and does not collect data from anyone.
